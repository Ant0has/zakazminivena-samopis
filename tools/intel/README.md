# ZM Intel

Состояние и общая очередь проекта ведутся в [корневом README](../../README.md). Этот каталог — сохранённая заготовка read-only мониторинга, не подтверждение работающего расписания. На 20.09.2026 основной домен и 301 с www уже внедрены; `/api/healthz` в рабочем приложении отсутствует, его проверка остаётся выключенной. Сначала настроить алерты и подтвердить источники, затем отдельно согласовать расписание.

Минимальный read-only контур наблюдения за `zakazminivena.ru`, конкурентами и официальными источниками. Он рассчитан на запуск с `temp-server`, а не с production.

## Что входит

- `health-check.mjs` — HTTP, canonical redirect и срок TLS;
- `watch-pages.mjs sources` — изменения официальных источников по релевантным словам;
- `watch-pages.mjs competitors` — изменения страниц конкурентов из исследования;
- конфигурация ключевых запросов и правил реакции;
- JSON-снимки и компактное state-состояние без копирования полных чужих страниц.

Скрипты не меняют сайт, CRM, Директ или внешние источники. Они делают только публичные GET-запросы с последовательной, низкой частотой.

## Проверка

```bash
npm run check
node scripts/health-check.mjs --no-save
node scripts/watch-pages.mjs sources --no-save
node scripts/watch-pages.mjs competitors --no-save
```

Проверка `www-canonicalization` ожидает уже внедрённый `301` на non-www. Проверка `application-health` настроена, но отключена флагом `enabled: false`; включать её только после отдельного внедрения `/api/healthz`.

## Рекомендуемое расписание после настройки алертов

- health: каждые 2 минуты;
- официальные источники: каждые 30 минут;
- конкуренты: раз в неделю;
- ключевые запросы/Вебмастер/Метрика/Директ/CRM: ежедневная выгрузка;
- полный sitemap-check: ежедневно с низкой скоростью;
- разведывательный brief: понедельник 09:00 по Москве.

Не включать расписание, пока не настроены:

1. Telegram destination для алертов;
2. правило «два последовательных сбоя» для health;
3. отдельные read-only OAuth-токены Яндекс API;
4. хранение секретов только в server env;
5. подтверждение правила: автоматизация только предлагает паузу рекламной группы, решение принимает владелец.

## Запланировано 16 сентября: ИИ-поиск

Добавить наблюдаемые ИИ-переходы, отдельный самоотчёт клиента, доступные отчёты Google/Bing и фиксированную панель вопросов о минивэнах. Актуальная очередь — в [обзоре проекта](../../README.md). Упоминание, цитирование, визит и заказ учитывать раздельно; ответы и найденные URL сохранять с датой, сервисом, режимом и регионом. Переходы/лиды смотреть еженедельно, панель — ежемесячно после подключения.

Повторяемая техническая блокировка, неверные факты о цене/вместимости или подтверждённый пробел в покрытии создают рекомендацию к действию. Ошибка сбора не означает исчезновение ZM. Это пока требования к расширению: коллекторы и расписание ИИ-мониторинга не реализованы и не включены.
