# Открыть граф ZM

Граф — автономный файл `index.html`: его можно открыть в обычном браузере без сервера и интернета. Данные встроены внутрь файла.

Для просмотра по адресу http://127.0.0.1:55310/ из этого каталога запустить:

```sh
node start.cjs
```

На рабочем Mac граф обслуживается локальной пользовательской службой macOS `ru.zakazminivena.site-graph`. Она запускается при входе пользователя и автоматически восстанавливает процесс при его завершении. Обычный detached-запуск из Codex дважды не пережил завершение работы, поэтому больше не используется.

`node start.cjs` проверяет службу и страницу; если служба установлена, но не загружена, регистрирует её в текущей пользовательской сессии. Второй сервер не создаёт. Сервер доступен только на этом Mac через `127.0.0.1`, не на внешнем сетевом интерфейсе. На другом компьютере использовать автономный `index.html` либо отдельно настроить локальную службу с правильными путями.

Настройка рабочей службы хранится в `~/Library/LaunchAgents/ru.zakazminivena.site-graph.plist`. Проверить состояние: `launchctl print gui/$(id -u)/ru.zakazminivena.site-graph`. Временные журналы: `/private/tmp/zm-site-graph-launchd.out.log` и `/private/tmp/zm-site-graph-launchd.err.log`.

[Шаблон службы](service.plist.template) не содержит личного пути рабочего Mac. Для другой машины заменить `__NODE_BINARY__` на абсолютный путь Node.js, `__GRAPH_DIRECTORY__` на абсолютный путь каталога графа; проверить `plutil -lint` и установить как пользовательский LaunchAgent. Не регистрировать незаполненный шаблон. При перемещении каталога графа сначала обновить пути службы.

Проверка после исправления 30.09.2026: `node verify-service.cjs` остановил только процесс локального графа через именованную службу; macOS автоматически запустила новый процесс без ручного запуска. Страница вернула HTTP 200, данные — 321 адрес и 12 предложений. Этот тест кратко прерывает локальный просмотр; рабочий сайт ZM не затрагивает.

`serve.cjs` — вариант работы в текущем терминале; после его закрытия адрес перестанет работать. Если ссылка недоступна, автономный `index.html` остаётся пригоден для просмотра.
